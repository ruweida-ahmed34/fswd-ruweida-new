# Jaamacadda Al-Amal (Al-Amal University) - Web Project

A modern, responsive, multi-page website designed and developed for **Al-Amal University (جامعة الأمل)** as part of the Responsive Web Design coursework.

---

## 🌟 Project Features

- **4+ Linked Pages:** Consistent layout across `index.html`, `about.html`, `courses.html`, and `contact.html`.
- **Fully Responsive Design:** Mobile-first approach supporting screen resolutions from **320px to 1920px**.
- **Modern Layout Techniques:** Built using **CSS Flexbox** for the header, navigation, and footer, and **CSS Grid** for main content cards and faculties.
- **Accessible & Clean Markup:** Semantic HTML5 elements with descriptive `alt` tags on all images to ensure high accessibility.
- **Working Contact Form:** Structured form layout ready for backend integration.
- **Pure HTML5 & CSS3:** No external frameworks, JavaScript, or AI-generated libraries.
- **Zero W3C Errors:** Validated markup using the W3C Validator Service.
